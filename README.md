# FlClashY

FlClashY — форк [FlClashX](https://github.com/pluralplay/FlClashX) на Flutter и Mihomo. Основная идея — подмена HWID и User-Agent для бесконечного количества устройств в VPN подписке. Платите за 1 слот, используете везде.

## Что добавлено в этом форке

Переносимый отпечаток устройства между Android и Desktop с HWID, моделью, версией ОС и User-Agent для Remnawave.
